# Explore Trenggalek 🌊🏝️

**Explore Trenggalek** is a tourism website designed to introduce and showcase the natural beauty, beaches, and tourist destinations of **Trenggalek, East Java, Indonesia**.

The website provides visitors with information about various coastal destinations and helps them discover interesting places to visit in Trenggalek.

## ✨ Features

* 🏝️ **Beach Destinations**

  * Pantai Prigi
  * Pantai Karanggongso
  * Pantai Blado
  * Pantai Kebo
  * Pantai Konang
  * Pantai Mutiara
  * Pantai Taman Kili-Kili

* 📖 **Destination Information**

  * Information about each destination
  * Beach descriptions
  * Visual gallery
  * Travel information

* 🗺️ **Explore Trenggalek**

  * Discover different tourism destinations
  * Easy navigation between destinations
  * Tourism-focused landing page

* 📱 **Responsive Design**

  * Desktop-friendly interface
  * Mobile-friendly layout
  * Responsive navigation and content

* 📩 **Contact Page**

  * Visitor contact information
  * Communication section for tourism inquiries

## 🛠️ Technologies

* JavaScript
* Responsive Web Design

## 🎯 Project Purpose

The main purpose of this project is to create a digital platform that introduces the tourism potential of **Trenggalek** to a wider audience.

Through this website, visitors can discover various beaches and tourism destinations while learning more about the natural beauty of Trenggalek.

## 🌴 Featured Destinations

### Pantai Prigi

One of the well-known coastal destinations in Trenggalek, offering beautiful coastal scenery and a relaxing atmosphere.

### Pantai Karanggongso

A popular beach destination known for its attractive coastline and tourism activities.

### Pantai Blado

A coastal destination offering natural scenery and a peaceful environment.

### Pantai Kebo

A beach destination with natural coastal landscapes suitable for visitors looking for a quieter atmosphere.

### Pantai Konang

A coastal tourism destination that offers beautiful ocean views and local coastal experiences.

### Pantai Mutiara

A scenic beach destination that highlights the natural beauty of Trenggalek's coastline.

### Pantai Taman Kili-Kili

A unique coastal destination that adds another attraction to Trenggalek's tourism landscape.
